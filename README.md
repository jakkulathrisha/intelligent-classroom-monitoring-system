# 🎓 Intelligent Classroom Monitoring System

An AI-powered CCTV monitoring system using computer vision to detect suspicious classroom activities and alert faculty.

## 📌 Project Overview

The Intelligent Classroom Monitoring System uses CCTV cameras and AI-based computer vision to monitor classroom activities. When suspicious activities are detected, the system captures evidence and sends an alert to the faculty.

## ✨ Key Features

- 📹 CCTV-based classroom monitoring
- 🤖 AI-based activity detection
- 📸 Evidence capture
- 🚨 Faculty alert system
- 🗄️ Activity and evidence storage
- 👨‍🏫 Faculty review dashboard

## 🛠️ Technologies

- Python
- OpenCV
- YOLO
- FastAPI / Flask
- MySQL
- IP CCTV / RTSP

## 🔄 How It Works

1. CCTV camera captures classroom video.
2. AI processes the video.
3. Suspicious activity is detected.
4. Evidence is captured.
5. An alert is generated.
6. Faculty can review the evidence.
